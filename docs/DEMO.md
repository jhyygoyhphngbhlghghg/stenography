# Видеодемонстрация — сценарий и чеклист

Пункт 7 отчётного материала. **Запись делает команда на живом телефоне** —
этот документ фиксирует сценарий, требования экспертов к стенду и слот, куда
кладётся файл. Рабочая папка: `docs/demo/` (чеклист — `docs/demo/README.md`).

## Слот под запись

Команда до сдачи (09:00) кладёт запись в **`docs/demo/demo.mp4`** (файл в
git не коммитим — `.gitignore` на `*.mp4` в демо-папках; публикуем как ассет
демо-релиза на [странице релизов](https://github.com/jhyygoyhphngbhlghghg/stenography/releases)
и оставляем здесь ссылку). Если запись не успевает — слот остаётся пустым, и
это честная дыра: он-девайс видео снимается только с физическим телефоном
(см. `docs/LIMITATIONS.md`). Уже существующее видео-доказательство живого
пути — GIF `artifacts/agent3/gif/deck-live-6spk.gif` (дек с 6 RU-репликами
с эмулятора на боевом сервере).

## Сценарий ролика (стенд presentConnect, ~3–5 минут)

1. **Установка.** `adb install -r app-presentConnect-debug.apk`
   (sha256 `b9afd39f…0d83` из релиза) — показать экран установки и первый
   запуск с распаковкой моделей (шкала в UI).
2. **Подключение.** В UI ввести токен `09879078` → **Connect + Live**.
   Показать `hello → hello.ok` в логе телефона и «телефон: на связи» в HUD
   дека `https://present.144.31.215.37.sslip.io/`.
3. **Передача через динамик и микрофон (непрерывно, одним дублем).**
   Источник звука — второй телефон/колонка, воспроизводящий
   `artifacts/demo-stage6-handoff/stem_or_slice_speaker_*.wav` (RU) или живая
   речь двух спикеров (RU и EN-фраза); приёмник — микрофон телефона с
   приложением. Расстояние между устройствами — в кадре (рулетка/маркировка,
   целевые 3–6 м по сцене DEMO_STAGE6). Запись не прерывается от начала
   передачи до появления строк на экране.
4. **Живые строки на деке.** Нажать `⏺ Live ASR → web`; показать, как реплики
   спикеров (RU, затем EN-фраза) появляются на экране зала и в HUD без
   перезагрузки (проверено: app→site push 78 мс, обновление <5 с — REPORT
   agent4). Держать пуш активным: при молчании >45 с дек уходит в
   «Резервный режим» (REPORT agent3).
5. **Экспорт и контрольные суммы.** **Сохранить JSON** → снять sha256
   исходного аудиофайла и экспортированного JSON (`sha256sum`), показать оба
   значения крупно в кадре (скриншот сравнения — отдельный артефакт).
6. **Логи.** Показать лог отправителя (`adb logcat` телефона: WS-кадры,
   `accepted:N`, `demo_phase:live`) и лог приёмника (`/v1/health` с
   `rows`/`phone_connected:true`, консоль браузера на деке, при наличии
   доступа — `journalctl -u neurosteno-web`).
7. **Финальный кадр:** фото/видео стенда целиком — телефон, источник звука,
   экран, видимое расстояние.

Параллельный офлайн-дубль (основная заявка DEMO_STAGE6, авиарежим): импорт
диалога → расшифровка → JSON — по сценарию `artifacts/demo/README.md`.
