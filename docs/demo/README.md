# docs/demo/ — папка видеодемонстрации (пункт 7)

Здесь команда размещает материалы демонстрации перед сдачей (09:00).
Сценарий съёмки — `docs/DEMO.md`.

## Слот под запись (ПУСТО на момент коммита)

- **`demo.mp4`** — сюда команда кладёт запись стенда (или вставляет ссылку на
  ассет демо-релиза в `docs/DEMO.md`). Бинарник намеренно **не** создаётся и
  не коммитится: видео публикуется как release-ассет
  ([страница релизов](https://github.com/jhyygoyhphngbhlghghg/stenography/releases)),
  в git остаётся только эта заметка и текстовые артефакты.

## Чеклист стенда (требования экспертов)

Перед сдачей в этой папке должны появиться:

- [ ] `demo.mp4` (или ссылка на ассет релиза) — **видео непрерывной передачи
      через динамик и микрофон**: источник звука (колонка/второй телефон) →
      микрофон телефона с приложением → живые строки на деке
      `https://present.144.31.215.37.sslip.io/`, одним дублем, без монтажных
      склеек внутри передачи;
- [ ] `source-audio.wav` — **исходный файл** (что играл динамик; например
      `artifacts/demo-stage6-handoff/stem_or_slice_speaker_1_3m.wav`);
- [ ] `received-transcript.json` — **полученный файл** (экспорт приложения,
      схема брифа: `speaker_id`, `start_ms`, `end_ms`, `text`);
- [ ] `log-sender.txt` — **лог отправителя** (`adb logcat`: WS-подключение,
      `hello.ok`, пуши строк, `accepted:N`);
- [ ] `log-receiver.txt` — **лог приёмника** (`/v1/health` до/после, консоль
      дека; при серверном доступе — `journalctl -u neurosteno-web`);
- [ ] `checksums.png` — **скриншот сравнения контрольных сумм**: `sha256sum`
      исходного аудио и полученного JSON крупно в кадре; рядом
      `checksums.sha256` текстом;
- [ ] `stand-photo.jpg` — **фото стенда с видимым расстоянием между
      устройствами** (рулетка или маркировка в кадре; целевые 3–6 м по сцене
      DEMO_STAGE6).
