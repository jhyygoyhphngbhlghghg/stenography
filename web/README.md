# web — экраны и пульт презентации

Веб-часть «Нейро-стенографиста»: киберпанк-дек на anime.js, синхронизация всех
экранов через чекпоинты и пульт ведущего. Контракт с телефоном —
`docs/PRESENT_CONNECT.md` в корне репозитория (`present-connect/1`).

## Архитектура (один телефон ведущего)

```
телефон ведущего (микрофон + все модели)
        │  transcript.final / phone.status
        ▼
  web-бэкенд (Node, без аудио)
        │  checkpoint + transcript
        ▼
  экраны зрителей (QR) ── пульт ведущего
```

Телефон — единственный источник звука. Сервер **не принимает аудио** и не
распознаёт речь: он только принимает готовые строки в схеме брифа
(`speaker_id`, `start_ms`, `end_ms`, `text`) и рассылает их экранам. Это
сохраняет утверждение «всё считается на устройстве».

## Запуск

```bash
cd web/backend
npm install
ADMIN_TOKEN=<токен_ведущего> npm run build
ADMIN_TOKEN=<токен_ведущего> npm start          # порт 8080
```

- Экраны зала: `http://<host>:8080/` (или `/join?session=...`)
- Пульт ведущего: `http://<host>:8080/presenter` (вход по `ADMIN_TOKEN`)
- Телефон: `ws://<host>:8080/v1/present-connect?session=...&role=phone&device=phone_1`

Для репетиции без телефона:

```bash
npm run sim:phone -- --url ws://localhost:8080/v1/present-connect
```

## Чекпоинты и скролл

Дек — это 9 панелей-чекпоинтов (`SLIDES` в `backend/src/config.ts`). Анимации
каждой панели привязаны к скроллу через `onScroll(...)` anime.js
(`autoplay: onScroll({ container: '#scroller', target: section, sync: true })`),
поэтому прогресс анимации равен прогрессу прокрутки внутри панели.

Скролл у зрителей **заблокирован**: колесо, тач и клавиши перехватываются, а
сервер программно прокручивает дек к нужному чекпоинту. Листает только пульт:
`checkpoint.set / step / goto`. Зритель физически не может уйти вперёд или
назад — все экраны всегда на одном кадре.

## Режимы демо

| режим | когда | что на экране |
|---|---|---|
| `live` | телефон подключён, модели на месте | реальные `transcript.final` |
| `fallback` | телефон отключился / нет моделей / вручную | запись с явным баннером |
| `idle` | демо не начато | ожидание |

Резервные строки помечены `source: 'replay'`, симулятор — `source: 'simulated'`.
Ни те ни другие **не попадают** в экспорт `/v1/sessions/{id}/transcript` — там
только четыре поля брифа и только настоящие результаты.

## HTTP API

| метод | путь | кто | назначение |
|---|---|---|---|
| GET | `/v1/presentation` | экраны | чекпоинт (опрос 1–2 Гц, контракт §5) |
| GET | `/v1/sessions/{id}/transcript` | судьи | экспорт в схеме брифа |
| POST | `/v1/transcript` | телефон | пуш готовых строк |
| POST | `/v1/status` | телефон | статус запись/обработка |
| POST | `/v1/workers/register` | телефон | bring-up, возвращает `ws_url` |
| GET | `/v1/health` | мониторинг | сводка |
| POST | `/api/login` | пульт | вход по `ADMIN_TOKEN`, cookie |
| POST | `/api/command` | пульт | команды чекпоинтов и демо |
| GET | `/api/invite` | пульт | ссылка + QR для зала |

WebSocket `/v1/present-connect?session&role&device` — роли `phone`, `screen`,
`presenter`. Пинг каждые 15 с (контракт §2), 45 с молчания телефона — fallback.

## Тесты

```bash
npm test
```

6 интеграционных тестов поднимают реальный сервер: раздача дека и защита от
обхода пути, авторизация пульта и чекпоинты, доставка транскрипта на все
экраны, fallback при потере телефона, HTTP-инжест без WebSocket, запрет
«живого» режима для сборки без моделей.

## Дизайн

Стерильный киберпанк в духе документации anime.js: светлая «бумага», чернильный
текст, два сигнальных цвета (cyan/magenta), линейки 1px, моноширинный для данных.
Палитра и типографика — `public/css/style.css`. Анимации — `public/js/deck.js`.
